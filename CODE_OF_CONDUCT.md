# Contributor Covenant Code of Conduct

## Our standards

Contributors must be respectful, constructive, and inclusive. Do not harass, intimidate, publish private information, or use project channels for abuse.

## Enforcement

Report unacceptable behavior privately to the project maintainers listed by the repository owner. Maintainers may remove comments, reject contributions, or restrict participation when needed to keep the project safe.

This project follows the Contributor Covenant in spirit and may adopt a future version by updating this file.
